# RSNA-Knee-Abnormality-Detection

## 目的
MRI画像から12種類の膝の疾患の可能性を判別する。

### 対象疾患
1. ACL tear：前十字靭帯の高度（50％以上）もしくは全層断裂。ピボットシフトや骨挫傷などの二次所見を含むものと含まないもの両方
2. MCL tear：内側側副靭帯の高度もしくは完全断裂。靭帯内及びその周辺に繊維断裂と浮腫が認められる。
3. Medial Meniscus tear：少なくとも2枚の画像において半月板表面に接触している異常信号、あるいは内側半月板に認められる断片の欠け、縮小、変位などの形態学的異常
4. Lateral Meniscus tear：外側半月板での同様な異常
5. Medial compartment osteoarthritis：軟骨厚の50％以上の中等度もしくは高度の内側コンパートメントの膝軟骨欠損。軟骨化骨髄の変形を含むものと含まないもの両方
6. Lateral compartment osteoarthritis：外側コンパートメントでの同様な異常
7. Patellofemoral compartment osteoarthritis：膝蓋大腿関節での同様な異常
8. Joint effusion：関節内への中程度もしくは大量の滲出
9. Synovitis：滑膜の腫脹もしくは炎症
10. Baker (popliteal) cyst：膝裏側の特異的な位置への滲出
11. Contusion：骨挫傷。外力による骨髄浮腫に似た信号として観測されるが、明確な骨折線は確認されない
12. Acute fracture：急性骨折

## 評価指標
ROC-AUC：12種類の疾患のROC-AUCを計算し、その平均をモデルのスコアとする。  
ちなみにROC-AUCとはPositiveと判定する確率の閾値を変化させていったときのTPR(真陽性率)とFPR(偽陽性率)をプロットした曲線の面積。  
ある閾値を境に、完全に陽性と陰性が分かれていればスコアは1になる。

簡単にまとめ  
- MRIは軟部組織（靭帯や骨髄など）を同時に見るのに適している。
- 今回のコンペでは12種類の膝損傷に絞って分類（対象疾患を参照）
- MRI画像は3種類（axial：輪切り、coronal：正面から、sagittal：横から）
- MRI画像の種類によって見やすい損傷は異なる（半月板や靭帯はcoronal、膝蓋大腿関節軟骨はaxial）
- 流体感受性シーケンス（プロトン密度強調画像やT2強調画像）は、しばしば脂肪抑制と併用され、浮腫や滲出を白く検知するのに用いられる
- 半月板損傷では複数の画像において、半月板の表面に達する信号の増強として現れる
- その他のシーケンスも解剖学的特徴を強調するために撮影されているため、同じ膝に対する複数画像の知見を集合させることが必要となる
- MRI画像の差は僅かなので、読影医によって判定が分かれることや、筋骨格系に特化した専門医へのアクセスも限られているため、ツールの必要性が高い
- 曖昧な結果やボーダーラインとなるものは特異度（正しく陰性と判定される割合）を優先するため陰性と判定された。
